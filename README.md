# Steam Game Importer (Fork) for Playnite

Fork of [Steam Game Importer](https://playnite.link/addons.html#Steam_Game_Importer) v2.11 by darklinkpower, with fixes and new features.

## Changes (v2.12)
- **Fixed running-state tracking:** the game's install directory is now set automatically, so Playnite correctly detects when the game is running.
- **Installed games list:** pick from your installed Steam games and add them in one go.
- **Steam cache artwork:** icons and covers are loaded from the local Steam cache.

## Installation
1. Download the latest `.pext` from [Releases](../../releases).
2. Double-click it or drag it into Playnite.
3. Restart Playnite.
